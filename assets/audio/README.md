# Звуки первой версии

Все WAV-файлы в этой папке — **синтезированные, стилизованные звуки**, созданные
специально для проекта. Это не полевые записи настоящих животных. Внешние сэмплы,
модели генерации речи и материалы со сторонними лицензиями не использовались.

| Файл | Содержание | Длительность |
| --- | --- | --- |
| `frog.wav` | Мягкое кваканье | 1,80 с |
| `duck.wav` | Кряканье | 1,80 с |
| `grasshopper.wav` | Три серии стрекотания | 1,90 с |
| `bee.wav` | Плавное жужжание | 1,85 с |
| `pond.wav` | Тихий ветер, вода и далёкие птичьи трели, зацикленный фон | 16 с |

Формат: моно, PCM 16 bit, 24 000 Hz. Начала и окончания отдельных звуков смягчены.
У фона сведён стык для повторения; он рассчитан на существенно меньшую громкость,
чем звуки персонажей. Никакие файлы не скачиваются во время работы приложения.

Воспроизведение набора из корня проекта:

```sh
python3 scripts/generate_audio.py
```

Скрипт использует только стандартную библиотеку Python, фиксированный seed и
проверяет непустую амплитуду. Он печатает длительность, пик, RMS и размер файлов.

Сами сгенерированные WAV-файлы предоставляются по **CC0-1.0**:
<https://creativecommons.org/publicdomain/zero/1.0/>. Их можно заменить
достоверными записями животных с подходящими лицензиями перед выпуском обучающей
версии; файлы в этом прототипе прежде всего демонстрируют механику приложения.

Рассказы из `data/nature.ts` читает системный синтезатор речи через `expo-speech`.
Наличие и качество русского голоса зависит от устройства; готовые записи диктора
в этот набор не входят.
