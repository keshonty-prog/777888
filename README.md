# Привет, природа!

Первая версия мобильного приложения для знакомства детей до трёх лет с природой. Написано на TypeScript, React Native и Expo SDK 58; один проект для Android, iOS и браузера.

## Что работает

- Главное меню: животные и насекомые, крупные иллюстрированные кнопки.
- Животные: земноводные и птицы; насекомые: обитатели луга.
- Короткие рассказы на русском. После завершения рассказа открывается пруд; его также можно открыть сразу.
- Пруд с четырьмя интерактивными персонажами: лягушкой, уткой, кузнечиком и пчелой.
- При нажатии персонаж анимируется и воспроизводит свой звук. Частые нажатия не накладывают несколько голосов друг на друга.
- Тихий зацикленный природный фон, общее выключение звука и отдельное выключение фона.
- Отмена звука и речи при уходе со сцены или сворачивании приложения.
- Раздел для родителей. Регистрации, рекламы, аналитики и серверной части нет.

Это первая локация приложения. Лес, ферма, млекопитающие и другие темы ещё не реализованы.

## Запуск

### iPhone и компьютер Linux

Ссылка на снимок экрана в чате показывает только изображение. Она не устанавливает и не запускает приложение. Адрес сервера внутри облачной среды также не становится доступным вашему iPhone автоматически.

Для запуска у себя:

1. Установите на Linux Node.js 24 LTS, на iPhone — Expo Go из App Store.
2. Распакуйте архив проекта на Linux. Подключите компьютер и iPhone к одной Wi-Fi сети.
3. Откройте терминал в распакованной папке и выполните `bash start-linux.sh`.
4. Дождитесь QR-кода. Отсканируйте его обычной камерой iPhone и выберите открытие в Expo Go.
5. Разрешите Expo Go доступ к локальной сети, если iOS спросит. Терминал на компьютере оставьте открытым.

На iPhone нужна версия Expo Go, поддерживающая SDK 58. Если появляется сообщение о несовместимой версии, обновите Expo Go. Если QR-код не подключается, убедитесь, что устройства находятся в одной обычной, не гостевой сети; проверьте разрешение локальной сети для Expo Go и доступ к порту 8081 через брандмауэр Linux. Публичный сервер или TestFlight для этого способа не нужны.

### Команды разработчика

Проверено с Node.js **24.19.0** и npm **11.9.0**. Рекомендуется Node.js 24 LTS; Expo также поддерживает ветки 22.13+ и 26+.

```sh
cd /workspace/777888
npm ci
npm run web
```

В другом окружении перейдите в фактическую папку клонированного проекта вместо `/workspace/777888`. Браузерный адрес и QR-код выводит Expo CLI. Скрипты запуска используют `--offline`: это отключает обращения CLI к сервисам Expo, но позволяет раздавать приложение по локальной сети.

Чтобы открыть на телефоне:

```sh
npm start
```

Установите Expo Go с поддержкой SDK 58 и отсканируйте QR-код. Телефон должен иметь сетевой доступ к компьютеру с Metro. В изолированной облачной среде доступ с личного телефона зависит от сетевых возможностей платформы; локальная браузерная проверка не подтверждает доступность QR-кода с телефона.

`npm run android` и `npm run ios` запускают приложение в настроенном эмуляторе/симуляторе. Для Android нужен Android SDK и эмулятор, для iOS — macOS и Xcode. Они не устанавливаются через `npm ci`.

Если пользовательский каталог недоступен для записи, задайте Expo отдельную папку:

```sh
mkdir -p /tmp/little-nature-expo
chmod 700 /tmp/little-nature-expo
__UNSAFE_EXPO_HOME_DIRECTORY=/tmp/little-nature-expo EXPO_NO_TELEMETRY=1 npm run web
```

В Expo SDK 58 `EXPO_HOME` не меняет каталог настроек CLI. Приведённый shell-параметр — предусмотренный CLI способ перенаправления этого каталога. Используйте отдельную закрытую папку и задавайте параметр только в команде, не в проектном `.env`; на обычном Linux с доступным домашним каталогом он не нужен. `.npmrc` сохраняет кэш npm в `/tmp/little-nature-npm-cache`, не требуя записи в домашний каталог.

## Как устроена озвучка

Все иллюстрации, шрифты и WAV-файлы поставляются вместе с приложением. Животные озвучены **синтезированными игровыми эффектами**, а не полевыми записями; происхождение и лицензия описаны в [assets/audio/README.md](assets/audio/README.md).

Рассказы читает системный синтезатор речи с русским голосом. Его нужно установить на устройстве; доступность офлайн зависит от выбранного голосового движка. Длительность зависит от голоса и обычно близка к 15–20 секундам. Если русского голоса нет, приложение показывает текст и позволяет перейти к пруду вручную. В браузере без голосового движка это ожидаемое поведение.

Фоновая музыка отсутствует: звучат тихие вода, ветер и стилизованные птицы. Микрофон не используется; настройки нативной сборки отключают разрешение записи и фоновое воспроизведение.

## Проверки и сборка

```sh
npm run typecheck
EXPO_OFFLINE=1 EXPO_NO_TELEMETRY=1 npm run export:all -- --max-workers 2
```

`export:all` проверяет сборку JavaScript/Hermes и ассетов для Android, iOS и web. Результат находится в `dist/`. Это **не APK/IPA** и не проверка на физическом телефоне. Для установочных файлов потребуется нативная или облачная сборка, идентификаторы приложения и, при необходимости, подпись.

Для отдельного статического веб-экспорта:

```sh
EXPO_OFFLINE=1 npm run export:web
python3 -m http.server 4173 --directory dist --bind 127.0.0.1
```

Экспорт не включает service worker: браузерная версия не устанавливается как офлайн-PWA.

### GitHub Pages

Для репозитория `keshonty-prog/777888` используется адресный префикс `/777888`. Отдельная команда подготавливает HTML, JS, шрифты и звуки с этим префиксом:

```sh
EXPO_OFFLINE=1 npm run export:pages -- --max-workers 2
```

Результат — папка `dist-pages/` с файлом `.nojekyll`. Её содержимое публикуется в корне ветки `gh-pages`. В настройках GitHub Pages нужно выбрать **Deploy from a branch → gh-pages → / (root)**. Создание ветки и включение Pages — отдельные действия; успешный локальный экспорт ещё не означает, что сайт опубликован.

`app.config.js` задаёт префикс только при `GITHUB_PAGES=true`, который выставляет команда `export:pages`. Обычная веб-разработка и нативная конфигурация используют исходные настройки `app.json`.

В другом терминале можно выполнить функциональные проверки:

```sh
python3 -m pip install playwright
npm run test:smoke
```

Скрипт использует `/usr/bin/chromium`. Для другого установленного браузера задайте `NATURE_CHROMIUM=/path/to/chromium`; для другого адреса сервера — `NATURE_BASE_URL`. Можно установить браузер командой `python3 -m playwright install chromium` и указать путь к нему. Эти инструменты нужны только для тестов, приложению они не требуются.

Проверки используют настоящий браузерный проигрыватель WAV: загрузку и движение времени, четыре голоса, отсутствие наложения, выключение звука, повторные нажатия и переходы. Отдельно проверяются размеры 390 и 320 px. Завершение русского рассказа и отменённые callbacks проверяются с явно подставленным TTS-движком; это не оценка качества системного произношения.

## Структура

```text
App.tsx                    экраны и переходы
components/AnimalArt.tsx    оригинальные векторные персонажи
components/PondScene.tsx    пруд и интерактивные области
components/UI.tsx           кнопки, значки, палитра
data/nature.ts              рассказы, группы и персонажи
hooks/useNatureAudio.ts    звук, речь, отмена и жизненный цикл
assets/audio/              локальные эффекты и природный фон
scripts/generate_audio.py  воспроизводимое создание WAV
scripts/smoke_test.py      браузерные функциональные проверки
```

Чтобы изменить рассказ, отредактируйте `data/nature.ts`. Для новых локаций добавьте сцену, персонажей и контент. Заменять игровые звуки реальными записями следует вместе с документированием их источников и лицензий.

Повторно создать звуки можно командой `npm run generate:audio`; достаточно Python 3, внешние библиотеки не нужны. Шрифты Nunito и Lora подключаются локально из npm-пакетов и распространяются по SIL Open Font License; лицензии находятся в `licenses/`.
